# Weekend Atlas

A standalone, responsive escape-discovery website. Search destinations, filter by region or mood, and save ideas for later. Saved places stay in the browser on the device where they were added.

## Run locally

Open `index.html` in a browser, or serve this folder with any static file server. There are no package installs or build step.

## Deploy to Vercel

Import the `weekend-atlas` folder as the project root in Vercel. No build command or output directory is required; the site is plain static HTML, CSS, and JavaScript.

## Notes

- Destination photography is loaded from Unsplash and requires an internet connection.
- The newsletter form is a front-end demonstration and does not submit addresses to a mailing list.
